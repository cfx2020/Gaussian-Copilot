## Gaussian Copilot v0.2.0

这次版本聚焦“作业看板可用性”和“集群场景正确性”。

### 亮点
- 作业看板支持自动发现：可直接识别 `qstat -u <username>` 中已存在的作业（包含安装插件前提交的任务）。
- 作业看板支持多选与批量操作。
- 新增右键操作：`打开选中gjf`、`重新提交选中gjf`。

### 改进
- 视图名称更新为“Gaussian 作业看板”。
- 命令文案统一为“可视化选中log/out”，并优化右键菜单排序。
- 同步调度器 `Jobname`，作业名称显示更可读。

### 修复
- 修复此前只显示“插件提交任务”的问题。
- 修复 `qstat -u` 解析错位导致名称和状态显示异常的问题。
- 修复同名作业在不同目录下点击打开错误文件的问题（增加 `qstat -f` 目录线索定位 + 人工选择记忆）。

### 兼容说明
- 新增配置：`gaussianCopilot.jobs.username`（可选）。
- 若留空，插件会自动从 `USER/LOGNAME/USERNAME` 推断用户名。
