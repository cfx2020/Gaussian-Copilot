## Gaussian Copilot v0.6.2

补丁版本，修复 `Sol` 路线中 `6-31g(d)` / `6-31g(d,p)` 未被正确升级的问题。

### 🔧 Sol 基组升级正则修复
- 修复 `6-31g(d)` 与 `6-31g(d,p)` 在溶剂化生成逻辑中的匹配错误。
- 之前由于正则边界写法不正确，这两种形式没有被真正替换，因此生成的 Sol 输入里仍然保留了原始 `6-31g(d)`。
- 现在以下形式都会稳定升级为 `6-311++G(d,p)`：
  - `6-31g(d)`
  - `6-31g(d,p)`
  - `6-31G*`
- `lanl2dz -> SDD` 保持不变。

### ✅ 影响范围
- `从当前帧进行Sol溶剂化`
- `进行Sol溶剂化（read方法）`
- 普通基组 route
- `genecp` / basis tail 中的轻原子基组定义
